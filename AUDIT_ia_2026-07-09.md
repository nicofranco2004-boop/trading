# AUDIT — Sistema de IA de Rendi (2026-07-09)

**Alcance:** Coach IA (chat SSE, tier-aware) + Análisis IA. Base `origin/main @ 1f1e42a`.
**Método:** fan-out 7 áreas → 17 bugs crudos → verificación adversarial (los 6 huérfanos por caída de conexión se re-verificaron con doble voto). **15 bugs confirmados** (3 High, 5 Medium, 7 Low) + 24 mejoras.

> **Titular:** el problema #1 no es el prompt ni el streaming — es que **la IA no ve valor de mercado ni tipo de cambio**. El snapshot que arma el frontend trae el costo de cada posición en su **moneda nativa mezclada** (pesos y dólares sumados 1:1) y **sin valor a mercado**. Es a la vez el mayor golpe de precisión *y* de conversión a Pro. Todo lo demás es secundario.

## B) BUGS DE CORRECTNESS (15 confirmados)

### 🔴 HIGH

**B-1 · `total_invested_usd` mezcla ARS+USD 1:1** — `AICoachDrawer.jsx:157-159,169` · 🆕 NUEVO
`buildSummary` suma `p.invested` de todas las posiciones **sin mirar `p.currency`** y lo etiqueta `total_invested_usd`. `invested` está en moneda nativa (backend devuelve `positions` crudo; `valuation.js` divide por MEP para USD) → la pata en pesos queda inflada ~MEP× (~1400×) y viaja así al LLM.
*Escenario:* CEDEAR comprado en 1.400.000 ARS + acciones US. "¿Cuánto invertí?" → "US$1,4 millones". Cualquier cartera con ≥1 posición en pesos (Cocos/IOL/Balanz) queda corrupta.
*Fix:* convertir por lote antes de sumar (reusar `costInPesos`/`costInUsd`). Se resuelve gratis con **M1**.

**B-2 · `positions` sin valor de mercado ni MEP** — `AICoachDrawer.jsx:58` · 📋 BACKLOG (ángulo nuevo)
El snapshot manda filas crudas: `invested`/`buy_price` en moneda nativa, **sin valor de mercado** (la tabla no tiene esa columna) y **sin MEP ni tool de FX**. El prompt no explica la conversión.
*Escenario:* "¿Cuál es mi posición más grande?" → compara números crudos cross-currency → CEDEAR de 2M ARS (~US$1.400) le gana a una acción de US$5.000. Elige el activo equivocado con confianza.
*Fix:* **M1** (market value USD por posición) + M4/M7 (MEP + regla en prompt). ⚠️ Trimear columnas (el fix de token-bloat) **NO** lo arregla.

**B-3 · El prompt promete benchmarks 3× que nunca llegan** — `main.py:12694, 12731, 17664` · 🆕 NUEVO
El system prompt asegura en 3 lugares que el snapshot trae benchmarks (S&P/inflación/blue). El snapshot real es solo `{summary, positions, operations, monthly, brokers}`; ninguna tool los provee. El `aiSnapshot` de `Insights.jsx` que sí los tenía es **código muerto** (prueba de que es accidental, no trade-off).
*Escenario:* "¿Le gano al S&P este año?" → el modelo **fabrica** el retorno del S&P y arma la comparación, porque el prompt le dijo que el dato estaba en el contexto. Cifra money-adjacent inventada.
*Fix:* adjuntar benchmarks reales (`/api/benchmarks` ya existe) **y** ajustar el prompt para usarlos solo si están presentes.

### 🟡 MEDIUM

**B-4 · Few-shot "bueno" del Pro modela consejo operativo prohibido** — `main.py:12850` · 🆕 NUEVO
El ejemplo etiquetado "Respuesta Pro (buena)" cierra con "considerar **tomar ganancia parcial**", que la regla `12762` lista como asesoramiento **prohibido**. El few-shot es la señal más fuerte para Haiku (imita ejemplos por encima de reglas). Toca la postura legal "no es asesoramiento".
*Fix:* reescribir el cierre a proceso, no acción ("definir un umbral de rebalance y revisar la tesis"). Alinear con `12762`.

**B-5 · Race: 2da pregunta a mitad del stream corrompe el historial** — `AICoach.jsx:135,138-142` · 🆕 NUEVO
El guard de `send` usa `loading`, que no cubre la ventana del stream in-flight → mandar otra pregunta mezcla los deltas en la misma burbuja **y cobra doble cuota**.
*Fix:* flag `sending` (ref) que quede `true` hasta el `finally` de `chatStream`; usarlo para el guard y los `disabled`.

**B-6 · Stream truncado se muestra como respuesta completa** — `api.js:181-214` · 🆕 NUEVO
Si el reader termina sin frame terminal (`done`/`error`), el cliente muestra lo acumulado como si estuviera completo → el user cree que esa respuesta a medias es toda la respuesta.
*Fix:* trackear `sawTerminal`; si el loop cierra sin él, lanzar error de truncación.

**B-7 · `get_stock_fundamentals`/`get_analyst_ratings` sin guard `.BA`** — `main.py:13495, 13985` · 🆕 NUEVO
El scorecard tiene el guard `currency!=USD && .BA` (`13683`, "Audit fix #4"); estas dos tools **no**. El dispatch de tools del LLM (`15618`) las llama directo → devuelven ARS bajo campos `_usd` (~1000× off). La descripción de la tool pone "TSLA.BA" como ejemplo. Analysts es peor: `"US$"` hardcodeado.
*Fix:* replicar el guard al inicio de ambos fetchers (rechazar `.BA` no-USD o convertir explícito).

**B-8 · `get_current_prices` no cotiza bonos AR** — `main.py:15178-15181` · 🆕 NUEVO
Resuelve solo vía `_fetch_one` (yfinance puro), sin `_resolve_ar_bond_price`/data912. `AL30` → `None`; `AL30.BA` → per-100 sin ÷100.
*Escenario:* "¿A cuánto está el AL30?" → null, aunque la Cartera del mismo user lo muestre.
*Fix:* fallback de bonos + `.BA÷MEP`, igual que `fetch_prices_for_symbols`. **(= M10)**

**B-9 · Race check-then-record en el cap de chat** — `main.py:17517, 17755` · 🆕 NUEVO
`can_chat` hace `SELECT SUM` sin lock; `record_chat` incrementa **después** del LLM. N requests concurrentes de un Free en 0/3 pasan todos → se sirven N llamadas contra el cap de 3. El patrón atómico ya existe (`_atomic_insert_fact:18053`) pero no se aplicó.
*Fix:* reserva atómica (INSERT-WHERE-cap) antes del LLM + refund si el LLM falla. **(= M22 lo mitiga parcialmente)**

### 🟢 LOW
- **B-10 · Prompt Free se auto-contradice en el largo del scorecard** (`main.py:12872`): "1-2 oraciones" vs formato de ~5. Además doble upsell a Pro back-to-back. *Fix:* excepción explícita para scorecard.
- **B-11 · `get_monthly_detail` LIMIT months×6** (`main.py:15216`): trunca multi-broker y mezcla la fila `global` agregada con las por-broker. *Fix:* filtrar por ventana de meses + `_note`.
- **B-12 · Costo en 2 unidades distintas** (`llm.py:91`): analyze en centi-centavos, chat en centavos. *Fix:* unificar a 1e-4 USD.
- **B-13 · Preámbulo de tool_use se streamea al user** (`main.py:17749-17761`): el path JSON lo descarta; el SSE no. *Fix:* frame de control `reset` antes de la síntesis final.
- **B-14 · `stripMarkdown` mutila aritmética con asteriscos** (`AICoach.jsx:57`): "2 * 3 = 6" puede colapsar. *Fix:* endurecer el regex de itálica (borde de palabra, no puramente numérico).
- **B-15 · Snapshot es texto libre sin escrubear** (`main.py:14799`): bypass de la whitelist Free + superficie de prompt-injection (un asset "IGNORA TUS INSTRUCCIONES..." entra al contexto). *Fix:* proyectar a esquema fijo, truncar strings, delimitar como DATO NO CONFIABLE.
